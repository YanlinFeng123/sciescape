# SCIEscape

Ideas beyond the syllabus. A responsive editorial website about economics, politics, and philosophy.

## Website

https://YanlinFeng123.github.io/sciescape/

This repository publishes directly from the main branch, root folder, using GitHub Pages. No build step is needed. Edit index.html, styles.css, or app.js and commit to main to update the site.

Economics includes Profit and Public Purpose, The Feeling Economy, and Marx: Alienation as a Social Relation. The first has a web reading view and the original DOCX download. The second includes a public PDF with the signed consent-form image omitted at the owner’s request; its essay and interview transcript are preserved. The three introductory reading guides remain separate from these essays. Contact details, team information, and contest details are awaiting the publication owner's input. There is no backend, submission form, or admin dashboard.

The supplied SCIEscape logo is included unchanged. Google Fonts has system-font fallbacks. Internal routes use URL hashes so that they work on GitHub Pages without server rewrites.

## Custom domain

www.sciescape.cn is not configured. Its ownership and availability are unverified. Once the domain is owned, verify it in GitHub, add it in Settings > Pages, then configure a www CNAME at the DNS provider pointing to YanlinFeng123.github.io. Enable HTTPS once the certificate is available.

Official instructions: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
